# Stage-1 `lamd7e4` deployment subset

This directory is the checkout-ready subset of
`results/stage1_single_ball_t128/default_v0_mppicost_lamd7e4`.

- `checkpoint_005.pt` is the only raw expansion state included. It preserves
  the exact final optimizer output but is not a standalone deployment file.
- `../checkpoints/stage1_lamd7e4_terminal_r5.pt` is the self-contained model
  Minhyuk should load through the canonical deployment loader.
- `manifest.json`, `metrics.jsonl`, and `task_config_resolved.json` bind the
  expansion recipe and task.
- `eval/raw_eval.json` is the raw temperature-one `M=20/gamma` audit.
- `eval/raw_gallery.{png,pdf}` is the canonical population gallery.
- The remaining files in `eval/` are presentation and mechanism artifacts
  generated by that same run.

Intermediate checkpoints, `events.pt`, `gp_evidence.pt`, `query_archive.pt`,
and local cache files are intentionally excluded. They are not needed to load
or deploy the terminal model and would add about 100 MB of training-only state.

## Governed deployment references

The `references/` directory contains a CPU-authenticated paired seed:

- [`expanded_r5_seed91074/manifest.json`](references/expanded_r5_seed91074/manifest.json):
  four successful gamma trajectories from the terminal model.
- [`pretrained_r0_seed91074/manifest.json`](references/pretrained_r0_seed91074/manifest.json):
  the same seed and gammas, all ending in collision before expansion.
- [`reference_search_audit.json`](references/reference_search_audit.json):
  the bounded search proving that the terminal policy has no authenticated
  successful below/above/right reference.

Every NPZ contains `dense_positions`, `states`, raw `controls`, governed
`executed_controls`, and `dense_steps`. The executed controls already include
the external governor once. All four r5 references are left-route successes;
they are deployable tracking candidates, not four-way coverage evidence.
